ORDER Workspace — แยกไฟล์

โครงสร้าง:
- index.html : โครงสร้างหน้าเว็บ
- css/style.css : CSS ทั้งหมด
- js/app.js : JavaScript ทั้งหมด (คงลำดับเดิม)
- js/saved-files.js : เก็บไฟล์ ORDER ที่เคยใช้ (หน้ารับORDER) ไว้ในเบราว์เซอร์ (IndexedDB) ล่าสุด 10 ไฟล์ เปิดกลับมาใช้/ลบได้ และเก็บใบปริ้น (รายการที่ปริ้นจริง + ไฟล์ PDF) เมื่อกดปุ่มปริ้น เพื่อใช้อ้างอิงในแท็บตรวจใบปริ้น อยู่เฉพาะเครื่องและเบราว์เซอร์นั้น
- js/scan-sheet.js : แท็บ "ตรวจใบปริ้น" อ่านกากบาท (✗) / วงกลม (○) จากรูปถ่ายใบปริ้น (ประมวลผลในเบราว์เซอร์ ไม่อัปโหลดรูปไปที่ไหน)
- css/theme-light.css : ธีมสว่าง สร้างอัตโนมัติจาก css/style.css ด้วย tools/build-light-theme.ps1
    * ถ้าแก้สีใน style.css ให้รัน: powershell -File tools\build-light-theme.ps1 เพื่อสร้างธีมสว่างใหม่
    * จุดที่ต้องปรับมือเฉพาะโหมดสว่างให้เขียนใน css/theme-light.extra.css (สคริปต์จะรวมให้)
    * ผู้ใช้สลับโหมดได้ที่สวิตช์ "สว่าง / มืด" ด้านล่างแถบซ้าย (จำค่าที่เลือกไว้ในเบราว์เซอร์)
- tests/ : ชุดทดสอบการอ่านใบปริ้น เปิด http://localhost:8934/tests/index.html (ผ่านเซิร์ฟเวอร์ในเครื่อง) จะรันรูปตัวอย่างใน tests/fixtures เทียบกับเฉลยใน tests/expected.json ถ้าแก้โค้ดอ่านรูป (js/scan-sheet.js) ให้เปิดหน้านี้ตรวจว่ายังผ่านทั้งหมด (รูปตัวอย่างเป็นใบปริ้นจริง เก็บไว้ในเครื่องเท่านั้น)
- js/sunshine.js + css/sunshine.css : ระบบ Sunshine (ใบสั่งซื้อล่วงหน้า / สินค้าขายดี ABC / ประวัติเคลื่อนไหวสต๊อก / นำเข้าข้อมูล) ที่รวมเข้ามา แท็บอยู่แถบด้านขวา ดึงข้อมูลจาก Supabase (ต้องต่ออินเทอร์เน็ต และโหลดเมื่อเปิดแท็บ Sunshine ครั้งแรกเท่านั้น) ค่าเชื่อมต่ออยู่ต้นไฟล์ js/sunshine.js
- supabase/op_setup.sql : สคริปต์สร้างตารางของ Sunshine รันครั้งเดียวใน Supabase > SQL Editor (แก้ 'CHANGE_ME' เป็นรหัสอัปโหลดก่อนรัน)
- js/move-rules.js : รหัสสินค้าแต่ละแบรนด์ + จำนวนย้ายเผื่อ ใช้กับปุ่ม "📦 ไฟล์ย้ายสินค้าแยกตำแหน่ง" (หน้าตรวจ ORDER กับ Stock) ซึ่งสร้างไฟล์นำเข้าใบย้ายสินค้าของ BigSeller 1 ไฟล์ต่อ 1 ตำแหน่ง ย้ายเข้า FRONT
- supabase/op_no_passcode.sql : ปิดรหัสอัปโหลด (ตั้งรหัสเป็นค่าว่าง) หน้าเว็บอัปโหลดโดยไม่ถามรหัส ถ้าฐานข้อมูลยังตั้งรหัสอยู่ หน้าเว็บจะถามรหัสเอง
- js/rz-fx2.js + css/rz-fx2.css : เอฟเฟกต์ RAYQUAZA ชุด 2 (ทำงานเมื่อเปิดปุ่ม ✦ FX) ต่อจาก js/rz-fx.js

    * ตัวเลขสถิติ (.sv / แถบสรุปสถานะ) นับขึ้นลงแบบ HUD + กรอบมุมเล็ง
    * ตอนระบบทำงาน (ปุ่ม ⏳ / แถบ progress) ขึ้นแถบชาร์จพลัง "DRAGON ENERGY" แล้วขึ้น COMPLETE ตอนเสร็จ
    * ปุ่มลับ: กด ↑ ↑ ↓ ↓ ← → ← → B A หรือพิมพ์ rayquaza (ตอนไม่ได้พิมพ์ในช่อง) = DRAGON ASCENT

    * แก้เว็บเสร็จแล้วให้สร้างไฟล์ติดตั้งใหม่: powershell -ExecutionPolicy Bypass -File installer\build.ps1
    * setup.cs = หน้าต่างติดตั้งธีมเดียวกับเว็บ (ภาพมังกร/พื้นหลังสามตำนาน, ป้าย DRAGON/FLYING, แถบ DRAGON ENERGY) กลางวัน 06:00–17:59 = MEGA ที่เหลือ = ไชนี่
      ไฟล์เว็บ + ตัวเปิดโปรแกรม (launcher.cs) ฝังอยู่ใน .exe ไฟล์เดียว · ตัวติดตั้งคัดลอกตัวเองเป็น uninstall.exe (/uninstall) สำหรับถอนการติดตั้ง
    * ติดตั้งลง %LOCALAPPDATA%\Programs\RAYQUAZA (ไม่ต้องใช้สิทธิ์ผู้ดูแล) สร้างไอคอนบนเดสก์ท็อป + Start Menu และถอนได้ที่ Settings > Apps
    * ตัวโปรแกรมเปิดเว็บจริง https://bctgamer100-web.github.io/RAYQUAZA/ เป็นหน้าต่างแอปของ Chrome (ไม่มีแถบที่อยู่) ในโปรไฟล์ที่โหลด stock-sync-extension ของ RAYQUAZA ไว้

    * ตัวติดตั้งรุ่นก่อนลงไว้ในชื่อ "ORDER Workspace" (ชนกับระบบเดิม) ถ้าพบ ตัวติดตั้งใหม่จะเสนอย้ายข้อมูลจากโปรไฟล์เก่ามาแล้วลบตัวเก่า (โปรไฟล์เก่ายังเก็บไว้)

ส่วนขยายเบราว์เซอร์ "ค้นหาสต็อก" (ใช้บนเว็บอื่น เช่น BigSeller):
- extension/ : ส่วนขยาย Chrome/Edge กด Tab บนหน้าเว็บไหนก็ได้ (ตอนไม่ได้พิมพ์ในช่องของหน้าเว็บ) หรือกดไอคอนส่วนขยาย เพื่อเปิดกล่องค้นหาสต็อกแบบเดียวกับในแอป
    * ค้นหลายรหัส · รหัสที่ไม่มีสต็อกขึ้นกล่องแดง · จิ้มเลือกตำแหน่ง/แก้จำนวน · โหลดใบย้าย (กติกาเดียวกับแอป: ลัง H ทั้งลัง, แยกไฟล์ H/K/C/J)
    * ดึงสต็อกจากฐานข้อมูล (op_stock) ใหม่ทุกครั้งที่เปิดกล่อง
    * ปุ่ม "📥 นำเข้า BigSeller": ถามยืนยันครั้งเดียว แล้วนำเข้าใบย้ายอัตโนมัติทีละไฟล์ (ใส่ไฟล์ > กดนำเข้า > กดปิดผลลัพธ์) ที่หน้า สินค้าคงคลัง > ย้ายสินค้า ถ้ากดจากหน้าอื่นจะเปลี่ยนแท็บเดิมไปหน้านั้นเอง (ไม่เปิดแท็บใหม่) หยุดเองถ้าผลลัพธ์มีรายการล้มเหลว (เหลือปุ่ม นำเข้าต่อ / ข้ามไฟล์ / ยกเลิก)
    * นำเข้าครบแล้ว: โหลดหน้าใหม่ ติ๊กเฉพาะใบย้ายที่เพิ่งสร้าง (แท็บ รอนำเข้า) กด "พิมพ์ใบย้ายสินค้า" แล้วในหน้าพิมพ์แคปภาพแต่ละใบ (เฉพาะใบสีขาว) บันทึกเป็น PNG ชื่อเลขใบย้าย ในโฟลเดอร์ดาวน์โหลด ใบย้าย_วันที่_เวลา
    * หน้า ตรวจ ORDER กับ Stock ในแอปมีปุ่ม "📥 นำเข้า BigSeller" ส่งใบย้ายชุดเดียวกับปุ่ม 📦 ให้ส่วนขยายนำเข้าอัตโนมัติ ในแท็บ BigSeller ที่เปิดอยู่ (ไม่มีจะเปิดแท็บใหม่) แอปที่ติดตั้งในเครื่อง (file://) ต้องเปิด "อนุญาตให้เข้าถึง URL ของไฟล์" ของส่วนขยาย
    * ติดตั้ง: เปิด chrome://extensions (หรือ edge://extensions) > เปิด "โหมดนักพัฒนา" > "โหลดส่วนขยายที่แตกไฟล์แล้ว" > เลือกโฟลเดอร์ extension
    * แก้กติกาใบย้ายในแอป (js/app.js moveFileKey / MOVE_FILE_ALIAS) ต้องแก้ใน extension/content.js ให้ตรงกันด้วย แล้วกดรีโหลดส่วนขยาย
